# 🚀 MC Tracker — Browser Extension Installation Guide

This extension injects the **Draggable Floating Action Button (`#03ad03` green button)** into **every browser tab and website** (Google, YouTube, Copilot, LinkedIn, etc.) so you can access MC Tracker Quick Actions from anywhere on your computer screen.

---

## 🛠️ Step-by-Step Installation (Google Chrome & Microsoft Edge)

### 1. Open your browser extension settings
- **Google Chrome**: Go to `chrome://extensions` in your address bar.
- **Microsoft Edge**: Go to `edge://extensions` in your address bar.

### 2. Turn ON Developer Mode
- In the top-right corner of the Extensions page, toggle **Developer mode** to **ON**.

### 3. Load the Unpacked Extension
- Click the **Load unpacked** button (top-left).
- Select the `extension` folder inside this project directory:
  `c:\Users\user\Desktop\MC Tracker\extension`

---

## ✨ Features & Usage

1. **Draggable Anywhere**: Drag the green Floating Action Button to any corner of your screen on any website.
2. **Viewport Boundary Clamping**: The button stays comfortably inside screen bounds on all window sizes.
3. **Quick Action Panel**: Click the button on any website to open the Quick Action menu to:
   - 💳 **Log Expense**
   - 📈 **Log Income**
   - 🎯 **Create Budget Plan**
4. **Live Mode Toggle**: Click the **MC Tracker extension icon** in your browser toolbar to toggle Live Mode **ON / OFF** across all tabs instantly.
